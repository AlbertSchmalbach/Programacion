CSS Moderno

1. Combinador :is()

Agrupación de selectores

Antes

        .container .item,
        .container .parent,
        .container .element {
            /* ... */
        }

Ahora

        .container :is(.item, .parent, .element){
            /* ... */
        }

2. Color RGB

Escribir colores

Antes

        .container {
            background: rgba(255, 255, 0, 0.5);
        }

Ahora

        .container {
            background: rgb(100% 100% 0 / 50%);
        }

3. Nesting CSS

Anidar código CSS

Antes

        .parent {
            background: grey;
        }

        .parent .element {
            background: darkred;
        }

        .parent .element:hover {
            background: red;
        }

Ahora

        .parent {
            background: grey;

            & .element {
                background: darkred;

                &:hover {
                    background: red;
                }
            }
        }

4. Centrado CSS

Centrar el contenido de un elemento

Antes

        .parent {
            display: grid;
            justify-items: center;
            align-items: center;
        }

Ahora

        .parent {
            display: grid;
            place-items: center;
        }

5. Variables CSS

Reutilizar información

Antes

        .parent {
            width: 300px;
            height: 300px;
            background: grey;
        }

Ahora

        .parent {
            --size: 300px;

            width: var(--size);
            height: var(--size);
            background: var(--color, grey);
        }

6. Media Queries

Sintaxis flexible de rangos

Antes

        @media (min-width: 800px) and
               (max-width: 1280px) {
        .menu {
            background: red;
            }
        }

Ahora

        @media(800px <= width <= 1280px) {
            .menu {
                background: red;
            }
        }
